# AE350 P1 原生启动与独立 JTAG 恢复

日期：2026-10-18。阶段提交，保留当前已验收能力与未完成项，不作为完整系统发布。

## 行为变化

- 138K使用AE350_SOC硬宏及原生32位ROM/64位SRAM端口，在8KiB ROM与8KiB SRAM中独立启动；不依赖DDR、SharedL2或Wishbone桥。
- 按无HSIZE的ROM接口语义返回完整32位字，修复读取字符串后续字节时的加载访问错误；SRAM对齐检查与ROM越界/写保护保留。
- 提供整数ABI的最小ROM monitor、trap报告和硬UART2控制台；移除额外硬件UART诊断与TX接管逻辑。
- 通过现有FTDIBUS/D2XX驱动连接独立CPU JTAG，统一板测入口支持CPU身份检查、完整ROM读回匹配、入口重启及恢复；摄像头接口引脚保留。
- 机器输入、工具、BSP、RTL与Python实现进入准确构建闭包；138K候选及输入变化与20K引用隔离。

## 验证与边界

主机检查覆盖存储协议、JTAG错误处理、机器输入隔离、组件构建和工作流；PnR、准确ROM字节读回、UART控制台/回显、ebreak及两次SRAM加载恢复分别保留证据。准确产物引用和收据在同名JSON与[当前上板记录](../ae350-p1.md)中。

本轮板测包含显式JTAG入口重启。自主启动首轮横幅捕获、timer/IRQ、实际CPU频率与压力表征、物理完整器件型号和板卡修订仍待确认。800MHz是配置目标，未宣称测频或上限压力通过；DDR尚未接入。

没有等价的AE350完整系统性能基线，20K all/cache基准不适用于此ROM阶段。本提交不创建产品版本、tag或发布条目；提交后保存源码、不可变组件闭包及板测证据的阶段快照。当前20K current/baseline不变，无Flash写入。

完整改动以Git记录为准；暂存区指纹保存在本地commit-checks，并在提交前校验。
