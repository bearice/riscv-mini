# AE350 P7：SD25、QSPI 与软件运行环境

2026-10-27。SD 默认使用 25 MHz、4-bit 原生接口和硬核 DMAC；用户 Flash U7 使用独立 sys50 QSPI 控制器，25 MHz、1-1-4 读取。AE350 BIOS 提供 FatFs 文件服务、UART/HDMI 终端和重新编译的 GW-BASIC。准确产物及原始回执见 [JSON](ae350-p7.json)，操作见 [运行环境](../docs/platforms/mega138k_ae350/runtime.md)。

最终硬件 `00edba753d33` 完整 STA setup/hold=0/0，最小脉宽裕量 +0.047 ns。CPU800、sys50、mem/DDR UI100、DDR CK400 MHz；逻辑 23896、寄存器 30735、BSRAM45、DSP4.5。SD 接收相位延后一 mem 周期，并在字 FIFO 前注册数据，保持既有跨域事务与 DMA 所有权。

| SD25 API 测速 | 512 B / 4 KiB / 64 KiB 各三轮通过，主机墙钟中位数约 1.28 / 3.10 / 3.11 MiB/s |

专用文件的主机独立 CRC32 分别为 `3d68bdcc`、`6ed0a415`、`c25f7ec4`。本轮保留 `/P7T000` 与 `/P7T001` 两个测试目录；文件测试使用 `FA_CREATE_NEW`，不格式化介质、不覆盖已有文件。测速区间包含文件系统元数据，创建文件后区间 CRC 会变化，本次九轮均为 `6123326f`。

组合负载使用与 BIOS 相同的 I/D cache 开启模式，SD 每约10ms读取4KiB并逐字节比对，重复检查1MiB完整文件 CRC。音频 TX、麦克风 RX 和 SD 分别独占 DMAC0/1/4；64KiB CPU 工作集超过 D cache。UART 每10秒记录 SD 读取进度，CPU 在完成标记之前保持运行。I-cache 关闭的组合候选出现欠载/溢出，未作为合格运行点。

QSPI 抽样页均为擦除态，四线的非平凡位序由 RTL 模型检查；本轮没有通过写 Flash 阵列构造物理测试图样。SD 物理拔插与超时故障注入尚未执行。声学刺激和主观听音不计入数字链路通过范围。

测试使用 FPGA SRAM 与 UART 装载。每次核对已安装启动固件的合同和实际字节，Flash 阵列、持久位流及 current 未更新。

长窗口完成后，原操作在 JTAG 结果读取阶段遇到 D2XX 短读，原回执保持失败。随后通过 `audio-suite --readback` 新建只读恢复回执：没有复位、重配置或再次上传，逐字节核对驻留代码与 ILM，读取完成状态和所有计数；数字检查全部通过。USB 采集因父操作读回故障而取消，已经完成的连续有效窗口为1807.675秒、图样错误0；恢复回执按这一已完成窗口验收，保留原始取消记录。后续长窗口在启动固件检查后释放 CPU 传输句柄，结束时重新建立连接。

组合负载结束后再次执行 BIOS 文件命令、77项 BASIC 自测、SD程序和图形检查，通过后清屏并显示 `/P7T001` 与 SD25 状态，CPU 已恢复运行。P7 全部结项仍需独立主机扇区参考及未执行的介质故障门禁。
