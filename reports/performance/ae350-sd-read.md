# AE350 SD 读取速度

2026-10-24，当前 10 MHz、4-bit 原生 SD + 硬核 DMAC 配置，大块 API 有效读取速度约 **2.84 MiB/s（2.98 MB/s）**，条件为 CPU I/D cache 开启。默认 bootloader 交接时 cache 关闭，实测约 0.22 MiB/s。

| API 调用大小 | cache 关闭 MiB/s | I/D cache 开启 MiB/s | 比值 |
| --- | ---: | ---: | ---: |
| 512 B | 0.216 | 1.258 | 5.81× |
| 4 KiB | 0.219 | 2.840 | 12.94× |
| 64 KiB | 0.220 | 2.824 | 12.86× |

每项从 LBA 2048 顺序读取相同 1 MiB，共三轮，表中取中位数。64 KiB API 调用仍由 BSP 内部拆成最大 4 KiB 传输，因此与 4 KiB 调用接近。此结果包含 SD 命令、DMAC、缓存同步和 bounce copy；不是单独的卡介质或 DMA 总线峰值，也不是 FatFs 文件读取速度。未调节 SD 时钟，未加入音视频并发。

两组共 18 个样本 CRC32 全为 `1201fe31`，guard 全部通过，初始化/读取/停止错误均为 0。CRC 在读取计时区外执行；无软件块缓存，所有样本均调用真实 SD 传输。CRC 为重复读一致性检查，未和独立主机卡镜像比对。

计时使用主机单调时钟对 UART START/END 行打点，整个读取过程不暂停 CPU，同时记录 64-bit 周期计数；完成后才通过 JTAG 检查结果。关闭 cache 组观测周期频率中位数约 799.7 MHz，与配置 800 MHz 一致。UART 行长差与主机调度产生毫秒级误差，原始值和逐样本墙钟/周期见 [结构化报告](ae350-sd-read.json)。初始化、CRC、SRAM 配置与载荷上传不计入读取时间。

位流 `c0856d5475c0`，baseline 载荷 `24c77ac4817d`，cache 开启载荷 `b1b603a53cab`。准确构建/板测回执、原始周期、CRC 和配置均在 JSON 中关联。首次 300 秒主机等待超时的部分运行保留且排除；最终完整两组使用 600 秒预算。

全程只读卡、不写 Flash、不修改 current。结束时 SD 请求门关闭、DMAC 通道排空，CPU 驻留于测速完成后的 WFI，I/D cache 为开启状态；两只 FTDI JTAG A 接口已恢复原驱动绑定。
