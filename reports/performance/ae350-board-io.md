# AE350 板级 I/O 验收与内存对照

2026-10-21。约定范围验收通过；风扇调速、停转及硬件改动按用户要求暂缓。当前 gateware `44405c059cf8`，sys 80 MHz、mem/UI 100 MHz、DDR CK 400 MHz；只写 SRAM，不改 Flash/current/原内存 baseline。

## 功能与证据

共享事件和 WS2812 核心、20K Adapter、板级 LED/按键、GPIO/fabric PLIC ISR、并发 DDR/DMA 和版本化 I/O 结果合同通过。数字 I/O 为 1000 次事件/1000 次服务，GPIO source=7、fabric source=17，trap 记录为零、mcause=0x8000000b；DMA 忙时服务 282 次中断，CPU/DMA 数据无错。DDR 13 项检查/0 失败，DMA 10000 次传输通过。精确回执与 SHA256 见同名 JSON。

灯、按键和颜色保留此前用户观察的候选归属，不把旧观察写成新候选目视。当前源码重新构建的 I/O、DMA 和 DDR 套件二进制与此前实测产物一致，并补做当前源码产物的执行验证。普通 LED 输出来自板级寄存器，硬 GPIO IOPORT 未启用。

STA setup=0、hold=0、最小脉宽 +0.142 ns；sys Fmax 80.008 MHz、mem Fmax 100.061 MHz，裕量很小，不作频率上限声明。

## 边界

片内温度使用厂商典型常数，签收采样通路，不签收绝对精度。风扇保持配置后的默认持续导通，栅极/测速实验接口保留，但不声明调速或停转可用。DMAC 自身 CPU ISR、专用 fabric reader、频率扫描及正式实时 DMA 外设的忙通道保护/错误传播仍独立跟踪。历史试验过程不在本文重复，查原始回执和提交快照。

当前无风扇写入的演示已通过上传/执行检查，JTAG 结果区温度有效、错误为零，观察到 31.5–32.0 ℃。后续被动 UART 采集为空，故不把周期串口输出列为通过项；原始观察保留在快照中。这不替代物理灯色观察。
