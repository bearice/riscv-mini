# AE350 P2 评审修复状态

2026-10-19 独立复核已否定上一版“17/18 均修复、R12 默认接受风险”的结论。用户没有接受 CDC 风险。当前实现与验收结果以 [独立修复报告](ae350-review-acceptance.md) 和显式候选生成的 [验收汇总](ae350-p2-acceptance.json) 为准。

本轮修复包括：

- R01：自动扫描多个相同目标时拒绝猜测；显式 FPGA 位置贯穿请求、会话和编程器。
- R02/R03：DEAD 正确返回两周期 ERROR；恢复不再产生虚构请求；已发读超时后保留所有权，吞掉迟到数据；互连接受的恢复期请求不丢失；默认错误从设备支持完成拍下一地址。
- R04/R05：地址与 loader 范围合同在缓存查询前进入输入与配置；ROM 地址头/链接片段归档；主机与 ROM 检查相同大小和入口规则，payload 清单、文件哈希、machine、ABI 都在硬件前验证。
- R06/R13：SRAM 子区域和 ROM 末尾状态保留区保持独立，构建/链接检查继续生效。
- R07：UART 接收与交接不虚报执行；执行核验使用实际 payload 字节区间，不能把整个装载窗口当代码。
- R08：payload 独立构建真正消费用户 --source/--source-dir，公共启动代码从诊断目录分离，二进制路径属于 artifact；有正式 result artifact，并纳入构建实现输入；操作必须显式选择 payload，取消全局最新文件猜测。
- R09/R10：普通 run/recover/verify 按 profile 分派，具名不可变请求校验参数；不支持的旧参数明确拒绝；兼容上传入口也做硬件前校验。
- R11：上传、恢复、DDR 诊断和 JTAG 探针共用会话所有权/互斥锁；串口、日志、JTAG 和锁在异常路径释放，清理失败使回执失败；恢复前按实际依赖 ROM 做读回比对。
- R12：校准/lock 经同步器进入 sys，多位 recorder 经一致快照握手；真实 FIFO 与不同比例时钟仿真已纳入正式测试。完整时序还检查 minimum pulse width，不能只看 setup/hold。
- R14：新独立回归进入 tests 发现入口，覆盖旧测试遗漏的负向行为；原适配器与互连测试继续单独运行；新增生产 AHBMemory + 当前零基址译码 + 真实 AsyncFIFO 的联合测试，性能采样/信息输出不再充当功能 PASS。
- R15：遍历从 DDR 零基址开始，保护整个运行镜像（含 data/bss）；覆盖元数据区分每块两字和八字。
- R16：主机暂停计时包括最终 halt 和最后读结果时的暂停，压力范围和原始计时分开记录，不推算为已实测 CPU 频率。
- R17：POST 保持短自检与 ROM 摘要的真实口径，不代替完整 DDR 验收。
- R18：汇总固定 gateware/payload 身份、保存真实完整回执路径；缺证据保持 untested，不再硬编码 build/timing/review 全通过。

先前归档 `ae350-p2-08234b4ff228` 不再作为完整交付快照：它复制的 ROM artifact 不是该 gateware 的实际依赖。旧文件保留用于审计，不原地修改历史哈希。

本轮没有实现 burst 合并、读行缓存、DMA、XIP 或原子指令支持。时序通过、仿真通过、实板通过分别记录，不相互替代。
