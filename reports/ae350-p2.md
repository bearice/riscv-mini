## 覆盖与计时

全窗口遍历：33,554,105 个 32 B 块、1,073,731,360 字节，8 words/block、0 错。排除当前完整运行镜像 `[0x3000, 0x58e0)`（含 ILM 装载镜像、data/bss，向 32 B 边界取整），共 10,464 字节；不是沿用旧 SRAM/mailbox 排除区。栈和结果位于 DLM，不占 DDR 遍历空间。容量标签还覆盖高地址，测试上限为 `0x40000000`。

重配置校准 10/10，状态 0x203/0x20b，计数 160524–160639 个 80 MHz sys 周期，约 2.007 ms；这是 FPGA SRAM 重配置后的重新校准，不称为物理冷启动。IP 自主训练，JTAG 只读观察。

短压力：1 MiB，一轮、0 错；cycle budget 为配置频率的 5 秒。实际压力运行 6.563 秒、墙钟 6.594 秒、JTAG 暂停 0.031 秒。整套测试约 85.7 秒，不把整套墙钟当压力时长。30 分钟长跑和低频 CK 扫描不属于本次门槛。

压力计数已改为 RV32 高/低/高一致读取 64 位 mcycle，防止单轮跨低 32 位回绕而漏算。Windows counter 标定使用高分辨率 QPC，普通阶段标记保留串口接收与轮询量化误差。

## 性能 baseline 与解释

[内存 baseline](performance/ae350-memory-baseline.md) 保存三次原始样本和 JSON。ILM 中的隔离测试、DLM 栈，64 KiB、32-bit volatile，写回计时包括 clean/fence。cached read 约 34.02 MiB/s、cached write 约 25.35 MiB/s、cached copy 约 14.33 MiB/s；均为 counter-rate 换算估值，不是 DDR 引脚峰值。

与同载荷的写聚合前候选相比，cached write 吞吐约 +15.6%、cached copy +9.0%；独立 uncached write 的 cycles 约 +16.7%（吞吐约 -14.3%），uncached copy 约 -2.8%，read 基本相同。4→1 条 UI 写不等于端到端速度提高四倍。独立 32-bit NONSEQ 仍消耗整条 32 B UI 传输，仅 cache-line burst 的宽窄转换已充分使用整块；后续优化以真实 baseline 比较。

外设/ITCM 80 MHz 是当前配置点，来自已有 snapshot，不是 AE350 固定比例或已证明的上限。已退役 standalone monitor 的 100 MHz BSRAM 失败不用于解释当前平台频率；本轮未单独证明当前 ITCM 结构的 sys=100 MHz 失败。数据口 100 MHz 已通过完整 STA/实板，133 MHz 历史尝试不作为当前构建结果。

## 接口与限制

- 本轮没有写 Flash，没有改 20K current 或性能 baseline，也没有创建版本/tag/push。当前机器的 baseline 由本报告和性能报告显式命名。
- 原子 LR/SC/AMO 不发布为 fabric DDR 能力；不重复运行会挂起的探针。硬核 cache write-back 不代表 DMA 硬件一致性；DMAC/共享仲裁、XIP、HDMI、FPU/MMU/timer-IRQ 软件尚未纳入本轮。
- ECC 检查显式关闭，未验证纠错能力。复位支持协调断言和各域异步释放；任意单域运行期热复位不支持透明续跑，完整恢复用平台重配置。
- 聚合写是 posted write：提前完成表示缓冲接收，不能追溯撤销已应答 beat；延迟故障由 sticky/后续事务错误报告。CPU fence 不等同硬件 cache clean 或多主持久化屏障，P3 所有权交接须单独实现并验证排空合同。
- 应用入口不返回，应用可覆盖 ILM；恢复必须从 bootloader 入口重新初始化本地内存，不直接调用已覆盖的 CRC 段。
